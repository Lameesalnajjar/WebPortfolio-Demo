# WebPortfolio Demo - Docker & GitHub Basics

## Project Description
This is a lightweight static web portfolio application containerized using **Docker** and hosted on **GitHub**. Built as part of the Operating Systems Lab Assignment to demonstrate automated deployments and containerization best practices.

## Tech Stack
* **Frontend:** HTML5, CSS3
* **Web Server:** Nginx (Alpine-based lightweight container)
* **Containerization:** Docker
* **Version Control:** Git & GitHub

## How to Build and Run using Docker

### Prerequisites
Make sure you have **Docker Desktop** installed and running on your system.
